# Agent guide

The guide for an AI agent, or for a skill that tells one how to use Apple Reminders, is [SKILL.md](../SKILL.md) at the repo root. It has the rules, the date forms, one working command per task and the JSON keys. Full option lists are in [commands.md](commands.md).
